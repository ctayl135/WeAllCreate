# WeAllCreate

Your original branded website, extended with a Node.js 24 backend and persistent SQLite storage.

Start: `node --env-file-if-exists=.env server.mjs`, then open http://localhost:3000.

Tests: `node --test`.

See [LAUNCH.md](LAUNCH.md) for the audit, Stripe test setup, deployment steps, verification and remaining public-launch blockers. This is a local commerce beta, not a completed public production launch.
